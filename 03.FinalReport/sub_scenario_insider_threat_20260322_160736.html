2

NAS 기밀 탈취 (Data Exfiltration) — ✓ 성공

NAS SMB 서버에서 제품 설계도(21개 파일)와 TeamCity API 토큰을 탈취합니다.

Critical

실행 결과

NAS 서버(445/SMB) 포트 개방 확인
내부자는 별도 취약점 없이 업무 권한의 SMB 클라이언트만으로 NAS에 마운트하여 기업 핵심 자산(제품 설계도, CI/CD 토큰)을 조용히 복사할 수 있습니다.
smbclient //nas/data -U smbuser%smbpass

탈취 대상: 제품 설계도(PDF), TeamCity API 토큰, 내부 키 파일

4

내부 DB 접근 (Lateral Movement) — ✓ 성공

획득한 크리덴셜로 내부 MySQL DB에 직접 접속, 고객/직원 정보를 덤프합니다.

Critical

실행 결과

내부 DB 포트 스캔 결과:
  • spring-db:3306 (고객 데이터): OPEN
  • struts-db:3306 (직원 데이터): OPEN

Phase 3에서 획득한 DB 크리덴셜로 방화벽 없이 내부망 MySQL에 직접 접속하여 고객 정보 및 직원 정보를 전체 덤프할 수 있습니다.

mysqldump -h spring-db -u spring_user -pspring_pass spring_db > /tmp/spring_dump.sql
5

공급망 공격 (Supply Chain Attack) — ✓ 성공

TeamCity 토큰으로 CI/CD를 장악하고, Gitea에 악성 코드를 push하여 자동 배포를 유도합니다.

Critical

실행 결과

CI/CD 인프라 통신 확인:
  • TeamCity (teamcity-server:8111): 네트워크 오픈됨
  • Gitea (gitea:3000): 네트워크 오픈됨

내부자는 업무 권한 Gitea 계정으로 소스코드를 수정하고 push합니다. TeamCity가 자동으로 빌드/배포하면 프로덕션 서버에 백도어가 삽입됩니다.

6

백도어 삽입 & 흔적 은폐 (Persistence) — ✓ 성공

프로덕션 서버에 백도어를 심고 git log와 bash_history를 수정하여 범행을 은폐합니다.

Critical

실행 결과

Gitea 저장소 통신 상태: 
GITEA API REACHABLE (3000/TCP)

시뮬레이션 시나리오:

  1. Gitea에서 spring-server 레포지토리 clone
  2. ApplicationController.java에 숨겨진 원격 실행 엔드포인트 삽입
  3. 정상 기능 commit 메시지로 위장하여 push
  4. TeamCity 파이프라인 자동 빌드 → 프로덕션 배포
  5. git log 수정, bash_history 삭제로 흔적 은폐
